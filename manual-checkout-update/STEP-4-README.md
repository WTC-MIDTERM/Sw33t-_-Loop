# Step 4 — Add an optional customer note

This note lets a customer write extra requests, for example: `Please call when you arrive` or `No nuts, please`.

Open [step-4-note-changes.txt](step-4-note-changes.txt) and follow its five small changes. The note is optional, so Place Order still works when it is empty.

After the backend schema change, restart the backend:

```powershell
Ctrl + C
npm run develop
```
