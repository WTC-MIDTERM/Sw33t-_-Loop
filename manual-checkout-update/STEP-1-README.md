# Step 1 — Replace the cart-page files

Download the three files in this folder.

Replace these files in your project with the matching downloaded file:

| Downloaded file | Replace this project file |
| --- | --- |
| `cart-page.ts` | `sw33tloop-frontend/src/app/pages/cart-page/cart-page.ts` |
| `cart-page.html` | `sw33tloop-frontend/src/app/pages/cart-page/cart-page.html` |
| `cart-page.css` | Copy its CSS changes into `sw33tloop-frontend/src/app/pages/cart-page/cart-page.css`; do not replace the whole file. |

This step adds the required phone number field, makes delivery visibly required, and saves a guest's checkout information. Do not test Place Order until you finish Steps 2–4, because the backend still needs to accept the phone number.
